## Verdict (read this first)

G still holds. The `Dx9Vulkan*` types remain a **first-seen opcode
catalog**. Several rows are **PROVEN** or **EQUIVALENT** (clip-Y
flip only at `ToVulkanWvp`, `D3DCULL_CCW` → CCW+Back, `LESSEQUAL`,
`W*V*P` push, landscape identity W on world STB, strip odd-t unwind,
PALSKIN `SRCALPHA/INVSRCALPHA`, fog `oFog` math, first-seen dirlight
polynomial).

The **live Present payload is still not a DX9 translation**. Native
submits:

1. per landscape **cell** (`00BF4570` DIP from stored VB/IB)
2. per static **instance** (`00BB2540` local copy + wrapper W)
3. per PALSKIN **primitive** (`00BD3070` file VB/IB + `c38`)
4. sky (`00B662F0` bit `0x2000`, different P)

Host `SubmitCurrentWorld` still does:

```
TessellateVisible → MeshBatches.Build(land)
BuildMeshes(primary C3Ds + hero 4299 CPU flatten)
Concat → one TexturedMesh
SilkEngineHost.Present → SetMesh + SetTextures
VulkanLineRenderer.Draw → one VB, CmdDraw ranges
```

That Concat / one-`SetMesh` is **DISPROVEN** as native-equivalent
(A, C, D, E, G, H). It is also the F hitch: ~30 s
`TessellateVisible` soup + a full VB memcpy on first Present.

Do **not** bake the entire scene into one buffer. The isolated
records in this pass are the host twin of the native units:

| Record | Native unit | Persistent thing |
|---|---|---|
| `LandscapeCellMesh` + `LandscapeDraw` | 16 m cell `00BF4570` | cell VB/IB (shared by bits `0x4` and `0x40`) |
| `InstanceDraw` `StaticLit` | `00BB2540` | file-local verts; W on the draw |
| `InstanceDraw` `Palskin` | `00BD3070` | file VB/IB + `PalskinPalette` (`c38`) |

Main agent wires those into submit / `Draw`. This investigation
does not change `SetMesh` semantics.

## 1. Persistent VB / IB

### Native — **PROVEN** (A, C, D, E)

| Unit | VA | VB | IB | Topology |
|---|---|---|---|---|
| Landscape cell | `00BFE050` / `00BF4570` | stride 24, stored `cell+56` | strip `cell+52`, `IndexCount = PrimitiveCount+2` | D3D strip |
| Static-lit | `00BB2540` | dynamic FVF `0x112` stride 32; **copy local, no matrix** | none | `DrawPrimitive` vtbl+400 |
| PALSKIN prim | `00BD3070` | file stride (28/`0x14` or 36/`0x16`) | file IB | `DrawIndexed` vtbl+332 |

Static-lit’s “persistent” object is the **file source**, not a
long-lived GPU VB. Native rebuilds a dynamic VB per DIP. Sharing
one GPU VB per `InstanceBufferKey` plus a per-draw W is a
**VALID BACKEND TRANSLATION** of “local verts + wrapper W”.
Concatenating every instance into one world VB is **not**.

### Host live — **DISPROVEN** as structure

```
MeshBatches.Build / BuildMeshes
  → MeshVertex[triCount*3]     // unwound list, world-baked
  → MeshDraw ranges
VulkanLineRenderer.SetMesh
  → one VkBuffer, host visible
DrawMeshBatches
  → CmdDraw(vertexCount, 1, firstVertex, 0)
```

`Dx9VulkanVertexFormat.HostStride = 60`. No `CmdDrawIndexed`.

`SilkEngineHost.Present` `ReferenceEquals`-skips a second
`SetMesh` when `BuildFrame` reuses `SubmittedMesh.Vertices`. First
submit still copies the whole soup. **LIKELY PERF**, not a
semantic map (H).

### Isolated type

`LandscapeCellMesh.LocalVertices` / `StripIndices` and
`InstanceDraw.LocalVertices` / `Indices` are the persistent CPU
objects. Do not merge them. Do not invent an IB by re-indexing the
Concat soup (G §2).

## 2. Per-object transforms

### Native — **PROVEN** owner (D), **PARTIAL** 3×4 pack site

```
clip = p_local * W_instance * V * P     // 00988A50 → c5–c8
W_obj  = instance 3×4 (00BB2540 / PALSKIN +0xEC)
W_land = T(cam) on camera-relative VB
W_bind = I
```

`009881F0` gathers 3×4 columns into wrapper+496 last-column
translation. Host `ObjectTransform` is last-row Numerics; `p * M`
is **EQUIVALENT** if the axes match. Feeding Numerics into a
last-column slot without the gather would swap axes (`CreateWorld`
failure mode — **DISPROVEN**).

×0.01 world scale site in the exe is **UNREAD**. Host folds it
into `ObjectTransform`. Mesh root 48-byte at mesh+176 **UNREAD**.

### Host live — **DISPROVEN** site

`BuildMeshes` bakes `ObjectTransform` into every triangle, then
`DrawMeshBatches` pushes `_worldViewProj = I * V * P` for
`0x20`. Land uses `_landscapeViewProj` which is the same I*V*P
(`HostLandscapeViewProjection`). Sky P split is **PROVEN** but
live Concat has **no** `0x2000`.

Y flip stays in `ToVulkanWvp` inside `Draw`. Baking it into
`009883F0` is **DISPROVEN**.

### Isolated type

`InstanceDraw.World` is that Numerics 3×4. `LandscapeDraw.HostWorld`
is identity. The VS product belongs at draw (`PackWvp(World, V, P)`),
not in the VB.

## 3. Descriptor / material / texture / pipeline caches

Native has **no** Vulkan cache. It has SetTexture + state blocks.
A host cache is allowed as a **VALID BACKEND TRANSLATION** of
“bind this id / this RS pair again”.

| Cache | Live | Native twin | Class |
|---|---|---|---|
| Texture image | `_textures[id]` rebuilt in `SetTextures` (`DeviceWaitIdle` + destroy pool) | CreateTexture at first use (`009BE8B0`) | Persist-by-id **missing**. Decode **PROVEN**. |
| Descriptor set | One set per uploaded image, rebound every draw | `SetTexture` stage 0/1 | **EQUIVALENT** role. No `(set0,set1)` pair object. |
| Material | `MeshDraw` (tex, tex1, blend, pass, mode) | cell stages / C3D material + Flag1 | Group-by-tex inside **one** native unit is allowed (G §12). Across cells+props: **DISPROVEN**. |
| Sampler | One LINEAR/REPEAT/`MaxLod=1` for every texture | `SetSamplerState` **UNREAD** | **TEMPORARY**. Do not “fix” to POINT without a dump. |
| Pipeline | 2 mesh PSO at `CreatePipeline` | VS/PS family + RS | Fork **EQUIVALENT** to opaque / PALSKIN. No sky / no PALSKIN VS PSO. |

Keys on the new records (not a cache implementation):

- `LandscapeBufferKey` / `InstanceBufferKey` → VB/IB

- `PalskinPalette` → `c38` upload (not a PSO)

`SetTextures` must become insert-if-absent. Destroy-all is
**DISPROVEN** as persist and is the H texture hitch.

### Fog — opcode **EQUIVALENT**, inputs **DIVERGE** (B)

`c0.y=1` `c18.w=1`. FS `rgb * oFog` toward black. `pc.cameraPos`
