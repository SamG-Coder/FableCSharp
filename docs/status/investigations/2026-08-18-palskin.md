### `00BCFB00` pack (the DIP bank)

For animated-block record `00A8E770`:

- count = byte at record **+23**
- bone ids = bytes at **+24** (the subset group)
- for `i in 0..count-1`: copy **12 dwords** from
  `dest[group[i] * 64]` into a packed buffer (3 float4s, **no
  4th row**)
- `SetVSConstantF(start=c38, count=groupN*3)`

VS: `mov a0.x, index*c1` then `c[38+a0]`. File blend bytes are
**register offsets** (0, 3, 6, …), not mesh bone ids.
`group[a0/3]` is the mesh bone used as dest index.

Host: `WorldShading.PackSubsetRegisters(palettes, group)` /
`PalskinGpuAddressOffset(slot)=slot*3`.
`PalskinPipelineTests.Father_file_byte_is_register_offset_into_00bcfb00_bank`
locks this. Adult 4299 sample0 is `idx=0,3` `w=85,170` — same
contract.
