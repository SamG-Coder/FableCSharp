## 6. Instance transform

### 6.1 Wrapper 3×4 → 4×4 — **PROVEN** (`009881F0`, 57 insns)

Source is 12 floats, **column stride 12** (48 bytes):

| Dest wrapper+496 (row-major 4×4) | Source |
|---|---|
| +496..+508 row0 | src+0, +12, +24, +36 |
| +512..+524 row1 | src+4, +16, +28, +40 |
| +528..+540 row2 | src+8, +20, +32, +44 |
| +544..+552 = 0, +556 = 1.0 | last row |

So source columns are `(axisX, axisY, axisZ, translation)`.
Dest has **translation in the last column** (`M14/M24/M34`).
Same layout as C3D 64-byte bone matrices (`WorldShading.ComposeLocalBone`).

`009881F0` clears `[wrapper+488]` (“world is not identity”) and
`or [wrapper+984], 0xC990` (dirty).

`00988290` writes sequential identity at the same slot and sets
`+488 = 1`.

This is DX9 `D3DMATRIX` column-of-basis / last-column T.
VS `dp4 oPos, pos, c5` (c5 = first stored row) is
`p.x*axisX + p.y*axisY + p.z*axisZ + translation`.

### 6.2 Host `ObjectTransform` — **PROVEN** as the C3D→region-local rule

```639:665:src/Fable.Game/WorldGeometry.cs
        var scale = MeshToWorld * ReadObjectScale(thing);   // 0.01 * ObjectScale
        var forward = ReadAxis(..., Vector3.UnitY);
        var up = ReadAxis(..., Vector3.UnitZ);
        var right = Vector3.Cross(forward, up);
        up = Vector3.Normalize(Vector3.Cross(right, forward));
        var basis = new Matrix4x4(
            right.X, right.Y, right.Z, 0,
            forward.X, forward.Y, forward.Z, 0,
            up.X, up.Y, up.Z, 0,
            position.X, position.Y, position.Z, 1);
        return Matrix4x4.CreateScale(scale) * basis;        // Numerics p * M
```

- **Baked vs world-matrix:** host **bakes** this into verts then
  uses `IdentityWorld()`. Native keeps W as this product.
- **Row/column:** host stores axes as **rows**, T in `M41..M43`.
  Native 3×4 stores axes as **columns**, T in last column after
  `009881F0`. `Vector3.Transform` (`p * M`) ≡ native `dp4` **if
  the axes match**. Uploading a Numerics last-row matrix through
  `009881F0` **without** the 3×4 column pack **swaps the
  convention** (the `CreateWorld` failure mode).
- **Multiply order:** `CreateScale(0.01*ObjectScale) * basis`
  (scale in mesh space, then basis+T). Native compose VA
  **UNREAD**; product is the working rule.
- **Basis:** `right = forward × up`, then `up = right × forward`.
  `CreateWorld` is **DISPROVEN** (Y-up, negates forward; lamp
  4978 laid on its side).
- **Pivot:** none. `p_local = 0` lands on TNG
  `CTCPhysicsStandard` position
  (`WorldPipelineTests.Static_tng_object_transform_places_local_origin_at_thing`).
- **Scale:** file packed scale = decompress; thing `ObjectScale`
  default 1; world `0.01 * ObjectScale` on the 3×3. Native
  `0.01` site **UNREAD**.
- **Handedness:** RH Z-up. Neighbour maps:
  `shift = T(ΔMapX, ΔMapY, 0)` after object.

## 10. Direct answers

**Baked vs world-matrix?**
Native is **world-matrix** (wrapper+496). Host is **baked** then
identity W. Numerically equivalent only if `ObjectTransform`
matches the 3×4.

**Row/column major?**
Native 3×4 source = **columns of basis**, T in the fourth column
of the 12-float block. `009881F0` writes a **row-major** 4×4
with T in the last column. Host Numerics = **rows of basis**, T
in last row. `p * M_host` ≡ native `dp4` if axes match. Do not
feed host memory to `009881F0` as-is.

**Multiply order?**
`clip = p_local * W * V * P`. Host W should be
`CreateScale(0.01*ObjectScale) * basis(right,forward,up,pos)`
then `* T(neighbour)`. Scale is in mesh space.

**Basis / pivot / scale / handedness?**
RH Z-up; `right = forward × up`; no extra pivot; scale
`0.01 * ObjectScale`; origin = TNG position.

**Native 3×4 at wrapper+496?**
`009881F0`: gather columns → rows; last row `(0,0,0,1)`; clear
`+488`; dirty `0xC990`.

**Instance transform site?**
Owner: `009881F0`. Static-lit source: 3×4 pushed through
`00B81640` / `00BB30A0` / `00BB2540` arg2. Builder from TNG
physics: **UNREAD**. Use `ObjectTransform`.

**FVF / stride / DIP?**
FVF `0x112`, stride 32, local gather, `SetStreamSource` +400,
`DrawIndexedPrimitive` +328. Host may keep unwound `CmdDraw`
per instance.

**Enough to delete flatten?**
Yes. Persist `MeshFile` local verts per mesh id; draw each
`WorldMeshInstance` with its `Transform` as W on layer `0x20`;
stop `BuildMeshes` `Vector3.Transform` and `Concat`.
